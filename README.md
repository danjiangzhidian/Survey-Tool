================================================================
 问卷调查系统 (Survey-Tool) — 项目简介
================================================================
一套部署在 Cloudflare Workers 上的轻量问卷调查系统。
单文件 worker.js 实现全部功能,零依赖、零成本运行,
不需要服务器、不需要数据库,复制粘贴即可上线。

官方仓库: https://github.com/danjiangzhidian/Survey-Tool

----------------------------------------------------------------
【核心特性】
----------------------------------------------------------------
▶ 纯 KV 存储,免费额度够用
  每天 10 万次读 / 1000 次写,内部调查、员工调研绰绰有余。
  无需 R2、无需 D1、无需任何外部服务。

▶ 单文件部署
  整个系统就是一个 worker.js(约 1000 行),粘贴到
  Cloudflare 控制台即可运行,5 分钟完成部署。

▶ 问卷编辑器(管理后台 /admin)
  · 五种题型: 单选题 / 多选题 / 评分题(★1-5,百分制) /
    文本题 / 下拉题,随时增删、改题型
  · 题目级设置: 必填标记、选项自由增删
  · 显示条件(逻辑跳题): 某题选了指定选项,后续题才显示
  · 问卷标题样式: 左/中/右对齐 + 自定义颜色
  · 问卷说明、答题口令(可留空)、每 IP 限填一次(防刷票)

▶ 数据统计 (/s/{id}/stats)
  · 每题作答人数、选项分布条形图、占比
  · 评分题自动算平均分 + 星级可视化
  · 独立 IP 统计

▶ 数据导出
  · 导出 Excel (.xlsx) — 零依赖手写 zip + OOXML,无需任何库
  · 导出 CSV
  · 大数据量自动分片: 超过 500 条时生成分片下载索引页,
    逐片下载,避免单次请求超时;KV 翻页修复了 1000 条
    静默截断问题,数据再多也不丢

▶ 填写体验
  · 移动端自适应,手机填写体验良好
  · 评分题星级点选、实时显示得分
  · 必填校验: 未完成时红色 Toast 提示 + 自动滚动到漏答题
  · 提交成功感谢页

▶ 管理后台体验
  · 登录有效期可选: 20 分钟 / 40 分钟 / 1 小时 / 2 小时
  · 退出登录按钮、右上角固定操作栏(预览问卷/返回列表)
  · 局部跳转(无整页刷新)+ 顶部加载进度条,操作丝滑
  · 未保存提醒: 编辑后未保存退出时弹窗三选一
    (保存并离开 / 不保存直接离开 / 继续编辑),
    关闭/刷新标签页同样保护
  · 自定义弹窗组件(替代原生 alert/prompt/confirm),
    动画过渡,风格统一
  · 保存成功绿色弹窗提示
  · 一键复制问卷分享链接
  · 新建 / 复制 / 删除问卷

▶ 安全
  · 管理密码登录 + 服务端会话(KV 存储,带过期时间)
  · 答题口令保护(可按问卷独立设置)
  · 所有输出 HTML 转义,防 XSS

----------------------------------------------------------------
【快速部署】(详见 部署教程.txt)
----------------------------------------------------------------
1. 修改 worker.js 第 11 行的管理密码:
     const ADMIN_PASSWORD = "1234";   ← 改成你的强密码
2. Cloudflare 控制台 → KV → Create namespace,名称 survey-kv
3. Compute (Workers) → Create Worker
4. Worker → Settings → Bindings → 添加 KV Namespace,
   Variable name 必须填: KV
5. Edit code → 粘贴整个 worker.js → Deploy
6. 访问 https://你的worker域名.workers.dev/admin 开始使用

绑定自定义域名、常用问题排查等,见随附的《部署教程.txt》。

----------------------------------------------------------------
【使用流程】
----------------------------------------------------------------
管理员: /admin 登录 → 新建问卷 → 编辑题目 → 保存
        → 复制分享链接发给填写者
填写者: 打开链接 → (如设置了口令则输入口令) → 答题 → 提交
管理员: 统计页看结果,导出 xlsx / CSV

【技术栈】
----------------------------------------------------------------
· Cloudflare Workers(运行时)
· Workers KV(存储)
· 原生 JavaScript,零框架、零依赖、零构建
· xlsx 导出为手写 zip + 内联字符串 OOXML,不依赖 SheetJS
· 前端无 React/Vue,纯字符串模板 + 原生 DOM,首屏即达
